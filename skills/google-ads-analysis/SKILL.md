# 广告分析总入口

本套为 1.0.3 只读分析版。本目录及三个相邻任务目录须完整保留。

## 开始

1. 先读 [数据约定](references/evidence-contract.md)。确认现有连接、目标账户、时区、币种和日期。没给账户 ID 时列出可访问账户；多个业务账户无法辨认时再请用户选择。
2. 查当前项目已有业务说明、上次报告及 `ads-analysis/business-context.md`，不去其他项目或凭据中寻找背景。只询问缺失且影响判断的主营服务、目标地区、有效客户定义、明确不做什么、竞品词策略。未知项保留为未知，继续不依赖它的工作。
3. “最近三天”默认账户时区最近三个完整日，明确列日期；比较上周同星期三天。用户指定范围优先。近期转化仍可能回补。
4. 按 [MCP 取数指引](references/mcp-recipes.md) 使用当前工具接口，不固定服务名前缀，不借用教师账户或安装另一套授权。

## 按问题选择

| 问题 | 读取的任务文件 | 交付 |
|---|---|---|
| 表现为什么变了、整体体检 | [表现诊断](../google-ads-diagnose/SKILL.md) | 优先问题、证据、验证步骤 |
| 搜索字词跑偏、应该否定什么 | [搜索字词审查](../google-ads-search-terms/SKILL.md) | 保留 / 待确认 / 待审 / 已覆盖清单 |
| 转化、价值、ROAS / ROI 可信度 | [转化核验](../google-ads-measurement/SKILL.md) | 动作与目标清单、可信度、缺证据项 |
| 复盘上次建议 | 表现诊断 + 旧建议清单 | 已执行情况、后续观察、未解决问题 |

只载入本次必要文件。复合请求可顺序执行；先判断转化能否支持经营推断，再讨论转化驱动的调整。各模块共享同一数据口径，不重复取同一份数据。

## 执行与交付

- 能通过现有 MCP 读取的数据直接获取，本地计算和生成报告直接执行。
- MCP 不可用时辨认工具未加载、权限不足、凭据失效等实际障碍；可分析用户导出并标来源。不要覆盖旧配置、重登共享 ADC 或静默安装替代连接。首次接入属于独立接入文档，本套不包含开户功能。
- 网页核对只用 Codex Computer Use，沿用用户常用浏览器。没有该能力时引导用户开启客户端的电脑操控及浏览器权限；登录、验证或实际权限不足才交还用户，不自行安装 Playwright。
- 按 [交付模板](references/deliverables.md) 生成独立 HTML。默认读者不懂广告：先解释发生了什么及对生意的意义，每条优先建议写清具体步骤、负责人、为什么做、预期帮助和检查效果的方法；术语首次出现就地解释，详细证据折叠后置。不能只列指标或“优化转化”等抽象任务。
- 给每项优先建议附可复制的继续任务，写明第一步从哪里开始、需要的最少资料。只读取数不等于可以执行变更。交付前在常用浏览器实际检查最终页面、复制、筛选、下载与窄屏阅读，能力受限时标明未验收；具体要求见交付模板。
- 详细数据保存在本地任务目录，不公开托管。不修改预算、出价、否定词、广告或转化设置。
- 按 [报告生成流程](references/pipeline.md) 将真实 MCP 回应适配、校验、补充业务判断并生成 HTML / CSV / 依据。附带可执行脚本和输入字段说明，无须从零写报告工具。脚本负责可重复检查，不能证明业务语义；资料不足时如实交付缺口，不编字段或引用让检查通过。
- 每次区分已确认事实、待验证解释和建议，列来源、窗口、读取时间与未覆盖项。不给用户输出长篇操作日志。

方法与官方资料见 [参考资料](references/sources.md)。
