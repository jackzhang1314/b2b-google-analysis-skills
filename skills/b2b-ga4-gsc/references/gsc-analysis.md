# 谷歌站长：什么需求找到网站，哪些页面值得改

## 先拆变化

1. 全站先看点击和曝光；再分查询、页面、主要国家和设备解释贡献。曝光表示被看见的机会，点击表示搜索结果被点进；两者都不等于采购人数。
2. 点击下降要区分曝光下降、点击比例下降与查询构成变化，不能只靠 CTR 定性标题差。CTR 用总点击/总曝光，不平均各行 CTR；平均位置受查询/市场/设备构成影响，不当固定实时名次。
3. 比较具体原词在相同范围内的两期表现；新增/消失词只标返回情况，不把未披露当零。少量曝光放观察，不依赖个位数点击作大范围改版。
4. 品牌分类先确认企业名及别称、域名、常见拼写，抽样检查中文/英文。未知规则不报确定品牌占比；查询明细未覆盖部分不直接当非品牌。

## 首页关键词

对已核实的完整首页 URL 做精确 page 筛选；同时读取首页独立总计与查询明细。查询词合计通常不能替代总体，报告明确已返回范围。默认只看 Web，需要图片/视频/Discover 时另列。

将已观察到的查询按采购目的组织，而不是只按词频：

- 企业/品牌寻找：保留清晰品牌识别。
- 产品、供应商、制造能力：首页概括主业务，具体产品/服务由对应页面承接。
- 行业、材料、工艺、认证和交期：根据真实业务匹配到已有能力页、案例或产品页。
- 学习/定义/教程：以有帮助的知识内容承接，相关时链接到服务，不承诺它一定带来询盘。

建议表每行写：原词、目标页面、两期点击/曝光/CTR/位置、业务需求、具体建议、证据限制。选少量最值得做的项，不能用几十个小词压过关键问题。

## 从数据到页面建议

| 情况 | 要确认什么 | 建议怎样表达 |
|---|---|---|
| 有曝光，点击少 | 相同查询的市场/设备/位置、实际标题与页面意图 | 说明页面能解决什么采购问题，给一版可审核标题/描述；没有 SERP 实看时保留结果样式未知 |
| 有采购词但页面内容弱 | 页面是否提供真实产品能力、数量/交期条件、证据和咨询入口 | 明确修改哪个段落、增加哪项已确认内容，以及为什么对买家有帮助 |
| 文章流量多，产品页弱 | 查询类型、相关性、站内路径 | 在适合的文章加入相关产品/服务入口，观察目标页访问及成功询盘 |
| 同一词出现多个页面 | 需求是否不同、查询在各页的稳定性、canonical 与实际页面 | 先分工；不能直接认定内耗或批量合并/删页 |
| 看似未收录 | 精确属性、URL Inspection 可用性、canonical/抓取结果 | 搜索表现没有数据不证明未收录；单页检查也不证明全站健康 |

写 Title、H1、摘要或首页结构前先读实际页面。保留已有有效品牌和主题，不把所有词塞进标题；所有能力、认证、产能和交期须业务证据，不能为关键词制造承诺。没有关键词量工具，不用 GSC 曝光冒充全市场搜索量。

SEO 实验先改少量明确页面和变量，记录原文与基线。用同词/同页面/同国家设备和足够观察期复盘，4–8 周可以是计划起点，稀疏需求延长；不是保证见效期限。未执行不能声称效果，排名改善也不直接等于询盘收益。
