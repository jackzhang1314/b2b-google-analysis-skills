# GA4、谷歌站长与页面

Ads 看买的流量与费用；GA4 看被记录的访问行为；GSC 看 Google 自然搜索。自然排名不是广告排名，不能直接推出广告询盘。

- 核验 GA4 属性与生产 hostname。分析本次付费访问使用 session 渠道，不用 firstUser 来源混代。
- 两期各取独立总计。用户跨天/页去重，不能加分组用户充当周期用户；会话分组有差异也保留独立总计并调查，不修平。
- `keyEvents / sessions` 是每会话事件数，可大于 1；有事件的会话比例用 `sessionKeyEventRate` 或对应事件率，不能混淆。
- 全站与 google / cpc 各取独立总计。直接访问异常不能直接归咎于广告；先看来源、国家、设备、日期和采集。明显低互动只支持异常线索，不能仅凭 GA 报表确诊机器人或无效广告点击。
- GA4 的事件计数并列不是漏斗，同名/近同量事件也不能证明逐人重复。使用原生 sessionGoogleAdsCampaignId 才可按系列 ID 做聚合对照；(not set) 保留，不按名称、日期或 URL 标签猜配。Ads 点击与 GA 会话不相等不等于追踪一定坏了。
- GSC 按 Pacific 日期，GA4/Ads 按各自属性/账户时区。GSC final 与 all/未完成日期分开；缺日行可能无数据，不能单凭缺行断定故障，也不能补零证明完整。查询词披露有限，不以查询行和替代全站总计。

## 落地页与首页关键词

1. 查实际投放最终 URL、重定向与 PMax 扩展，再取落地页/渠道。页面层比较不是用户或询盘级归因。
2. GSC 原始键保留完整 URL（协议、host、查询参数、尾斜杠）。canonical 合并另建有证据的映射并正确聚合；禁止截路径后 Map 覆盖。
   GA4 若需不含查询参数的落地页，优先另取原生 landingPage，保留 landingPagePlusQueryString 证据；不能加分行用户或平均行级率来拼页面总计。落地页资源的曝光也未必与系列曝光可加对账，分清资源语义后再算覆盖。
3. 首页用准确 page 过滤后取 query，明确属性类型与 Web。布局用较长成熟期；三日位次仅预警。
4. 词分品牌、主产品/服务、采购能力、信息研究和其他。品牌规则缺失为未知；不能把中文品牌经 ASCII 清洗变空匹配。
5. 高曝光/低 CTR 或有排名改善空间是候选，拆国家/设备/词群排除构成变化，不套 CTR 曲线承诺点击。平均排名不是固定名次。
6. 实际打开页面看 title/H1、首屏、能力/认证、MOQ/样品/交期、报价入口与移动端。不从 URL 猜页面，没看就标未核验。
   追踪 CTA 实际去向和选中的服务类型：含 prototype 的 URL 也可能实际是装配报价。截图或无障碍树没有可见 H1，只能说未观察到，不能断言源码无 H1。日常浏览器插件/地区/登录状态及手机模拟与真机区别写入限制；不把本机错误直接断言为全体访客故障。

首页承接清晰主业务和品牌；产品线/工艺/应用词评估分类、能力和产品页职责。多页出现同词不自动是内耗；看意图、搜索结果和表现。不堆词，不凭广告词替换稳定获客主题。

交付：页面 → 意图证据 → 当前问题 → 文案/布局草案 → 验证事件和销售质量 → 观察窗口。CTA/简表是假设，不保证质量改善；说明资格字段与反垃圾的权衡。
