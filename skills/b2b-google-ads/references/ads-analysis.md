# 广告诊断

## 从费用到原因

核对账户独立总计和系列总和，micros 除以 1,000,000 一次。分开 Search / PMax / 其他、品牌 / 非品牌、国家和设备；品牌规则缺失就不报品牌占比。用 ID 区分同名系列和实验组。

优先下钻对总花费或变化贡献大的系列。贡献用同粒度金额差；CPA/ROAS 从分子分母重算，不平均行级比率。归因转化可为小数；互动数不等于点击数。

| 现象 | 需要补查 | 条件建议 |
|---|---|---|
| 点击少、费用高 | CPC、字词、策略、份额/排名损失、改动与成熟度 | 调查流量价格/覆盖，不直接加预算 |
| 点击增、转化降 | 动作拆分、延迟、页面、表单成功证据、目标 | 区分测量、意图和页面问题 |
| 表单多、合格少 | 销售去重反馈、产品/市场匹配、垃圾/重复分类 | 调整吸引对象与资格筛选 |
| 预算份额损失高 | 可信 CPQL、利润目标、产能、共享预算与销售承接 | 满足条件再提有上限的增量实验 |
| PMax 表现差 | 渠道/字词披露、目标、品牌、实际落地页、网址扩展、素材 | 可见范围单独解释，不能归因全部花费 |

Google 优化分和推荐是排查线索，不是经营目标。同账户多个匹配关键词不自动意味着自己竞价抬价。不机械采用“三倍 CPA 必停”“一律加 20%”“30 个转化即可上某策略”等门槛。

### 当前配置与历史表现

- 系列名中的“手工出价”“品牌词”不是事实标签。读取真实 bidding strategy；品牌/竞品按实际字词和明确品牌规则判断。
- `Conversions` 随实际目标口径变化。某动作从 Conversions 消失但仍有 All conversions，先调查目标变更，不能推断事件停止或询盘流失。按动作 ID、系列和日读取两种列；比较同动作时仍保留触发/去重/归因设置变化和销售质量未知。
- 当前 custom goal 成员只能证明当前配置。变更记录、日序列给出历史线索；没有目标历史时不能编造切换日。预算当前值不等于历史日均花费，不把已经调低的预算再次当原高预算建议下降。
- 出价目标有变更时把 `conversion_comparability.status` 设 changed；未验证则 unknown。报告保留金额与次数，不把算术 CPA 变化包装成业务效率变化。

## 搜索词与否定词

1. 取实际搜索词，不拿关键词清单代替。保留原词、系列 ID、广告组 ID（来源有才用）、网络、日期。拆成日期/设备的行应正确聚合，一条有转化时不能把另一条零转化当整词零转化。
2. 返回词点击/费用与同系列、网络、日期分母比较。披露覆盖不等于完整性；limit、缺分页、来源不同都要说明。PMax 多渠道总量减字词量不能全部称“隐藏搜索词”。
   跨渠道/PMax 字词主查询不要加 `segments.keyword.*`：它会隐式过滤没有 Search 关键词的流量，接口可能成功但返回 0 行。先无关键词分段取数，再对 Search 做独立关键词分析；若工具生成的 SQL/GAQL 无法检查，零行应做最小字段对照，不直接下无数据结论。
3. 分直接采购、产品/工艺研究、品牌/竞品、明确排除、待判。OEM/ODM、MOQ、材料/认证、定制、交期、样品可能是采购意图；不能凭 how/free/repair 单词自动否定。原词保留中文、符号，聚类标签不覆盖原文。
4. 候选来自实际发生且客户明确不承接的意图。低样本/短期零转化/高 CPC 只能调查；待否定项补同范围较长历史（如 60–90 天，明确日期）和已确认询盘/成交，不仅看平台转化。
5. 查正向词、广告组否定、系列否定、共享表及关联、账户否定、品牌限制。匹配规则与范围同时查。否定不自动覆盖近似变体/同义词；中文、标点、重音等不能可靠模拟时留平台验证。
6. 正向与否定字面重叠不证明全部封堵。给出具体查询例子、规则与作用域，区分潜在限制和已验证阻断；不反推历史损失。

待审表列：原词、系列/广告组 ID、来源日期、费用/点击/平台转化、业务理由、历史证据、品牌/保护词检查、现有规则冲突、建议匹配类型/范围、潜在误伤、状态、复测指标。未知写待查；未完成检查不做可直接导入的否定文件，不把观察花费年化为保证节省。

已存在的否定词标为复测，不重复建议添加；历史产生过点击不证明当前规则失效，先查规则生效时间。精确否定词只覆盖其规则范围，不能把它当成整个长尾词族已封堵。客户另有 3D/CNC 等业务时优先讨论系列分流，不能在账户级整体封杀。已暂停的正向词也不等于同类查询以后绝不触发。

## 低样本与实验

零成功、n 个可视为独立且成熟的试次：二项模型 95% 单侧上界 `1 - 0.05 ** (1/n)`。重复点击、追踪不全、归因小数或未成熟数据不适用；这是不确定性说明，不是暂停线。

预算建议列基础预算、可承受实验损失、质量目标、成熟观察期和停止条件。变量尽量单一；明确坏链接可优先修，策略优劣用可比成熟队列/平台实验验证。无反事实证据，不把环比改善说成动作导致。
