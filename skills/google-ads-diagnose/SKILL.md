# 广告表现诊断

先读相邻 [数据约定](../google-ads-analysis/references/evidence-contract.md) 和 [取数指引](../google-ads-analysis/references/mcp-recipes.md)。缺少文件表示安装不完整，补齐同版本套件，不换 MCP。

1. **定问题。** 明确账户、两段时期、目标与业务成功定义。优先比较相同星期；有季节性、节假日、促销或目标变动时说明限制。
2. **核对总量。** 独立取账户总量与系列明细，保留期间有花费、但当前暂停/移除的系列。不得用当前 ENABLED 状态过滤掉历史花费。缺失与零分开；对账差额先排查取数。
3. **定位贡献。** 先看花费、点击、展示绝对变化，再看汇总后计算的 CPC、CTR。CPA、ROAS 只描述已定义的平台动作。涉及有效询盘、营收与利润，转 [转化核验](../google-ads-measurement/SKILL.md)。
4. **有限下钻。** 按影响最大的系列，选择必要的设备、地域、网络、关键词、搜索字词或落地页维度。用户所在地与感兴趣地区不能混合分母；PMax 不套用 Search 关键词指标。先取数再解释。
5. **检验原因。** 展示份额、排名/预算损失、出价策略、政策、学习期和变更记录提供线索，单项不证明应加预算。系列名称中写“手工”“品牌”等不证明当前策略或流量类型；读取实际策略字段和实际搜索词。变更与变化同日不是因果证据。近期转化下降先检查回补和采集。
6. **提出行动。** 最多三个优先问题，各列事实、解释、反例、建议验证、判断标准、负责方。核心业务高 CPC 不自动否定；高 CTR / 低 CPC 也不直接证明应扩量。

## 计算

- CPC = 汇总花费 / 汇总点击，CTR = 汇总点击 / 汇总展示。零分母为空，不平均行级比率。
- 可用对称分解解释花费变化：点击因素 = `(点击1−点击0)×(CPC1+CPC0)/2`；CPC 因素 = `(CPC1−CPC0)×(点击1+点击0)/2`。仅两期点击大于零、范围相同时使用，加总应等于花费变化。这是算术分解，不是因果证明。
- 不重复累加转化动作分行中的花费，不把 PMax 资产表现等级当可加收益。
- 不生成未经校准的健康分数，不把候选花费说成可保证节省金额。

按 [交付模板](../google-ads-analysis/references/deliverables.md) 输出，同一图表与表格使用同份聚合结果。否定建议转搜索字词模块。复盘时区分建议过与实际执行过，没有执行时间或控制变量不宣称 Skill 带来改善。
