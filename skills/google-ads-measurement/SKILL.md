# 转化与价值核验

先读 [数据约定](../google-ads-analysis/references/evidence-contract.md) 和 [取数指引](../google-ads-analysis/references/mcp-recipes.md)。

1. **独立列配置。** 读动作 ID、名称、状态、来源、类别、计数方式、主要/次要、价值设置、归因与窗口；再读系列默认/自定义目标及动作关系。跨账户先确定 conversion customer，权限不足标缺口，不把客户账户配置冒充完整清单。
2. **独立列表现。** 转化动作分段不带花费。按动作 ID / resource name 关联，不按名称。同名不同 ID 不合并；未返回的启用动作标本窗口无返回记录，不伪造为零或断言未触发。
3. **追到实际目标。** Primary 不代表每个系列都使用；Secondary 加入并应用自定义目标也可能参与优化。标准目标和自定义目标可同时应用，须取两者的并集，不能看见自定义目标就当成唯一目标。按系列目标组合比较平台 CPA；目标口径不同的系列不能直接排好坏。当前配置不证明过去配置；change_event 不支持所有转化相关资源，未返回不能证明目标未变。
4. **分别核验五层。** 前端触发 → 平台收到 → 去重/计数与归因 → 后台真实业务成功 → CRM 有效客户/收入。前一层通过不能替代后一层。上传 EXCELLENT 不等于有效询盘或营收。
5. **重复需要事件证据。** `all_conversions / conversions > 1` 仅提示拆解口径，不能认定重复；GA4 事件、Ads 归因转化和 CRM 客户也不能直接相除证明重复。需检查触发器、去重键、重复回传与后端成功记录；敏感标识不进入共享报告。
6. **解释价值。** 固定值可作业务代理目标，不自动判错，但不能叫销售额；低离散度只提示检查。读取 conversion_value_rule / conversion_value_rule_set 的启用状态、挂载和条件；设备等倍增规则会改变报告价值，不能把“转化数 × 当前默认值”当报告恒等式。当前规则仍不证明历史逐笔生效。没有毛利、成本、退款与一致归因数据，不给真实 ROI。平台价值/花费可标平台价值比；营收口径核实后才用于营收 ROAS。
7. **回补与成熟。** 结合窗口、业务周期、延迟和多次读取判断，不使用统一 72 小时规则。近期、小样本变化形成排查建议。

输出配置全量与本期表现覆盖对照；各动作五层状态为已证实 / 需排查 / 未知 / 不适用。空表不自动等于没有上传或转化。说明可用指标及补证步骤。

没有 CRM / GTM / 网站权限仍交付已完成的 Ads 检查并列缺口。网站测试提交、改采集须另有授权，本分析包不执行这些写入。按 [交付模板](../google-ads-analysis/references/deliverables.md) 输出。
