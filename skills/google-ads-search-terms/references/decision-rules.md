# 否定建议的判断顺序

| 证据 | 处置 |
|---|---|
| 核心产品、目标客户需求或保护词 | 保留；高 CPC / 三天零转化不是否定理由 |
| 业务范围或竞品策略未知 | 待确认；只问会改变判断的问题 |
| 本系列有历史转化，质量未核验 | 先核验；不能忽视历史直接否定，也不永久豁免 |
| 主转化为零，但当前/历史 All conversions 有信号或缺失 | 拆到具体动作核验；不是“没有转化”，也不直接认定有效询盘 |
| 完整现有规则已覆盖 | 已覆盖，不重复添加，不推断过去也生效 |
| 明确不做的意图、业务依据可追溯，历史及范围已查 | 待审建议，优先最小范围和精确匹配 |
| 只有高花费、低转化、小样本或阈值 | 排查候选，不足以判定应否定 |

账户级需证明所有受影响系列均不需要该意图；共享清单枚举实际挂载系列，不叫天然全账户。广告组级仅用于支持的类型与明确分流。

词组/广泛匹配扩大范围时，列可能误伤的有效搜索例子。本地脚本将这些情况留给专项审查，不自动判合格。大小写及部分拼写变体可由平台处理，但不据此声称覆盖所有单复数、同义词、语言和标点。最新规则见 [官方说明](https://support.google.com/google-ads/answer/2472708?hl=en)。本地字面匹配不模拟完整竞价引擎。

PMax 查询附关键词相关 segments 会丢掉 PMax，不将零行解释为没有流量。参见 [官方资源说明](https://developers.google.com/google-ads/api/performance-max/campaign-criterion-reporting)。
